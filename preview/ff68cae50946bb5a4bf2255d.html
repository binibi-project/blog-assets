클로드 소넷 5.5, 요금은 그대로인데 더 빨라졌어요

앤트로픽이 9월 28일 '클로드 소넷 5.5'를 출시했어요. 요금은 소넷 5와 같은데 속도는 30% 이상 빠르고 작업당 비용은 최대 30% 줄었어요.

요약
  • 요금은 그대로, 성능만 올랐어요: 9월 28일 나온 클로드 소넷 5.5는 소넷 5와 같은 가격인데 출력 속도는 30% 이상 빠르고 작업당 토큰 비용은 최대 30% 줄었어요.
  • 코딩 점수가 크게 뛰었어요: 에이전트 코딩 평가 Terminal-Bench 4.0에서 10.3%였던 점수가 70.6%로 올랐고, 지식 작업 평가에서는 한 단계 위 모델인 오푸스 5.5와 거의 비슷해요.
  • 이미 화면에 떠 있을 수 있어요: 구독료는 Pro 20달러·Max 100달러부터로 그대로예요. 클로드 앱에서 지금 쓰는 모델 이름부터 한번 확인해 보세요.

10.3%와 70.6%. 같은 에이전트 코딩 평가에서 석 달 사이 벌어진 점수 차이예요. 앤트로픽 공식 발표에 따르면 9월 28일 새 모델 '클로드 소넷 5.5'를 내놓으면서 생긴 간격이에요.

요금은 소넷 5와 똑같은데 속도와 점수만 올랐어요. 클로드를 매일 쓰는 분이라면 이 변화를 이미 화면에서 보고 있을 수도 있어요.

Terminal-Bench가 뭐예요?

AI가 터미널(명령어 창)에서 실제 개발자처럼 코드를 고치고 명령을 실행하고 결과를 확인하는, 여러 단계로 이어지는 작업을 끝까지 해내는지 측정하는 평가예요. 단답형 질문-답변보다 실제 업무에 훨씬 가까운 시험이에요.

토큰이 뭐예요?

AI가 글을 읽고 쓸 때 쪼개 쓰는 글자 조각이에요. 한국어로 치면 음절 하나하나에 가깝다고 보면 돼요. 앤트로픽 같은 회사는 글자 수가 아니라 이 토큰 수를 세어 요금을 매겨요.

🚀 속도는 30% 빠른데 요금은 그대로예요

클로드 소넷 5.5는 소넷 5보다 출력 속도가 30% 이상 빠른데 가격은 똑같아요. 입력 100만 토큰당 2달러, 출력 10달러로 소넷 5와 같은 요금표를 그대로 써요.

클로드 앱으로 긴 코드 작업을 맡기면 화면 한쪽에 토큰 사용량이 쌓이는 걸 보신 적 있을 거예요. 소넷 5.5는 거의 모든 평가에서 더 적은 단계와 평균 14% 적은 출력 토큰으로 같은 작업을 끝냈다고 밝혔어요.

예를 들어 소넷 5로 출력 토큰 10만 개가 들던 작업이라면 소넷 5.5는 약 8만 6천 개로 끝난다는 뜻이에요. 출력 가격이 100만 토큰당 10달러로 같으니 비용은 1달러에서 약 0.86달러로 줄어요(10만×$10÷100만=$1, 8만6천×$10÷100만=$0.86). 작업마다 줄어드는 토큰 비율이 다르니 "최대 30%"는 평균치가 아니라 가장 많이 아낄 때의 숫자로 보면 돼요.

📊 소넷 5.5가 오푸스 5.5보다 셀 수도 있다고요?

네, 에이전트 코딩 일부 항목에서는 한 단계 위 모델인 오푸스 5.5보다 높은 점수가 나왔어요. Terminal-Bench 4.0에서 소넷 5.5는 70.6%로 오푸스 5.5의 66.4%를 앞섰어요.

표만 보면 소넷 5.5가 오푸스 5.5와 거의 맞먹는 것처럼 보여요. 그런데 오푸스 5.5는 가격이 입력 100만 토큰당 4달러, 출력 20달러로 소넷 5.5의 두 배예요. 비슷한 코딩 점수를 더 싸게 받으려는 작업이라면 소넷 5.5 쪽이 유리해요.

💳 구독료는 그대로, 접근 범위만 넓어졌어요

클로드 프로·맥스 구독료는 이번에도 오르지 않았어요. 프로는 월 20달러(연간 약정 시 월 17달러), 맥스는 월 100달러부터로 전과 같아요.

앤트로픽은 가장 작은 모델인 클로드 하이쿠 5.5도 몇 주 안에 내놓겠다고 밝혔어요. 소넷 5(6월 30일)에서 오푸스 5.5(9월 22일), 소넷 5.5(9월 28일)로 이어진 흐름을 보면 당분간 몇 달 간격으로 모델이 계속 바뀔 것으로 보여요.

제 경우 저는 AI 앱을 하루도 안 거르고 써요. 유튜브·인스타그램·카카오톡과 함께 Claude·Gemini·ChatGPT를 매일 바꿔 가며 쓰는데, 가격은 그대로인데 성능만 오르는 이번 업데이트가 반가워요. 저라면 당장 다른 AI로 옮기기보다는 지금 쓰는 클로드 화면에서 모델 이름이 소넷 5.5로 바뀌었는지부터 확인해 보겠어요.
더 깊이
  • 반대로 보면 표의 점수는 전부 앤트로픽이 자체 공개한 결과고, 외부 기관이 독립적으로 재현한 검증은 아직 없어요. 독립 테스트에서는 사고 강도를 가장 높게 설정했을 때 토큰을 다 쓰고도 답을 못 낸 사례도 보고됐어요.
  • 구조 앤트로픽은 가장 비싼 플래그십(Fable·Mythos)과 오푸스, 소넷, 하이쿠 순서로 몇 달 간격을 두고 모델을 차례로 갈아 끼우는 전략을 쓰고 있어요. 소넷 5에서 오푸스 5.5, 소넷 5.5로 이어진 이번 석 달도 같은 패턴이에요.
  • 다음에 볼 것 클로드 하이쿠 5.5의 출시일과 가격이 다음 확인 포인트예요. "몇 주 안"이라는 표현이 실제 날짜로 바뀌는 시점을 보면 돼요.
자주 묻는 질문
소넷 5.5랑 오푸스 5.5 중 어떤 걸 써야 하나요?
일상적인 업무엔 소넷 5.5가, 더 복잡한 작업엔 오푸스 5.5가 맞아요. 앤트로픽은 소넷 5.5를 범위가 명확한 일상 업무와 버그 수정, 문서·슬라이드·스프레드시트 제작에 가장 적합하다고 소개했고, 오푸스 5.5는 플래그십 모델 수준의 작업에 쓰라고 안내했어요. 보고서 초안을 빨리 다듬는 일엔 소넷 5.5, 여러 자료를 깊게 분석해 결론을 내는 일엔 오푸스 5.5가 더 맞는 식이에요.
지금 바로 써보려면 어디서 써야 하나요?
클로드 웹(claude.ai)과 iOS·안드로이드 앱의 모델 목록에 소넷 5.5가 올라와 있어요. 개발자라면 API 식별자 claude-sonnet-5-5로, 아마존웹서비스·구글클라우드·마이크로소프트 애저를 통해서도 호출할 수 있어요.

저라면 요금 비교표보다 하이쿠 5.5가 나오는 날짜부터 챙겨 보겠어요. 그게 이번 모델 교체 흐름의 마지막 조각이거든요.

여기 적는 건 특정 서비스 추천이 아니에요. 출시 시점과 요금은 공식 발표에서 다시 확인해 보세요.
